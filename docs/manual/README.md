# Manual "Como funciona" (PDF)

`oraculo.html` é a fonte; `oraculo-tainacan-como-funciona.pdf` é gerado dela pelo Chrome:

    node gerar-pdf.js "<caminho absoluto>/oraculo.html" "<caminho absoluto>/oraculo-tainacan-como-funciona.pdf"

Requer `puppeteer-core` e o Chrome instalado (caminho no script). As capturas `oraculo-*.png` vêm do site de testes do TainacanBiblio.
